Static site; no build step or runtime dependencies are required.

The package includes index.html, 404.html, favicon.svg, and play-thumbnails-v75.jpg. Keep all files together when deploying so the refreshed game-card artwork loads.

VERCEL
- Upload this ZIP at https://vercel.com/drop, or extract it and deploy the folder with the Vercel CLI.
- CLI: run `vercel login`, then `vercel --prod` from this folder.

NETLIFY
- Extract the ZIP and upload the extracted folder at https://app.netlify.com/drop.
- The included netlify.toml publishes this folder as the site root.
